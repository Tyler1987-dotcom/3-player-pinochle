# 3 Player Pinochle — Support

Welcome to the support page for **3 Player Pinochle for macOS**, developed by Tyler McQuade.

## About the Game

3 Player Pinochle is a classic card game focused on bidding, meld scoring, trick-taking, and tracking gameplay statistics.

The game is designed for entertainment and strategic card play. It does not offer real-money gambling, wagering, or betting.
